### 📊 Project Overview
This project examines human–AI collaboration behaviour using survey data and behavioural analytics. It analyses seven behavioural dimensions and the Responsible AI Collaboration Index (RAIC) to understand AI usage, critical evaluation, verification, independent thinking, and responsible decision-making.
